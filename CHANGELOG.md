# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [2.8.1] - 2026-10-05

### Fixed

- Короткие подсказки поиска больше не блокируют сервер: книги ищутся по префиксу названия, авторы и серии — по префиксу имени
- Фоновый пересчёт каталога закрывает базу до снимка статистики и больше не удерживает процесс после завершения
- Счётчик «Найдено» не включает скрытые языки, жанры и удалённые книги
- Аннотации Flibusta из `annotations.7z`, записанные экранированным HTML, снова показываются разметкой на странице книги и в OPDS

### Changed

- В поиске схлопываются только копии одного издания. Другая серия, год, формат или язык остаются отдельными строками
- QR в боковой панели открывает страницу загрузки Android-приложения. Код входа в приложение остаётся в профиле
- Вход через OIDC подставляет логин, почту и группы из userinfo, если провайдер не кладёт их в id_token

[2.8.1]: https://github.com/Habsaec/inpx-library-server/releases/tag/v2.8.1

## [2.7.0] - 2026-09-27

### Added

- **Сжатые сборки Flibusta + Librusec** — ZIP с PPMd и другими методами кроме Store/Deflate распаковывается через 7z. В Админке → Контент картинки WebP внутри FB2 можно оставить или перекодировать в PNG при скачивании и конвертации
- **Дубликаты** — автоочистка и возврат скрытых книг с прогрессом и таймером. Кроме формата учитывается более новый источник, один id Флибусты в двух библиотеках и одно название при разном написании автора
- **Пользователи** — экспорт и импорт учёток (хеш пароля, почта, Telegram, избранное). Существующие логины не перезаписываются
- Переименование закладки (`PATCH /api/books/:id/bookmarks/:bmId`)
- Позиция, закладки, заметки, «прочитано» и история принимаются для локальных книг `local:<sha256>`
- В веб-читалке открываются PDF и TXT
- У сортировки каталога есть направление

### Changed

- На главной подпись героя — «Продолжить чтение»
- Имена авторов показываются с заглавной буквы
- Большой WAL усекается; счётчики авторов, серий и жанров обновляются по ходу очистки
- Листинг большого `.7z` не подвешивает HTTP и `/health`. Обложки, портреты и биографии авторов ограничены по времени
- Архив `.7z`, записанный в индексе как `.zip`, распознаётся при чтении файла

## [2.4.2] - 2026-08-03

### Added

- Режим **Список** (`?view=list`) в каталоге, поиске и новинках — строки как на Флибусте, с пакетным скачиванием
- На странице автора вкладки **Серии / Список** с групповым выбором и плавающей панелью скачивания

- После «Далее» в списке снова есть кнопка отправки на email
- Санитизация HTML аннотаций/био Flibusta: баланс тегов и очистка media-placeholder

## [2.4.1] - 2026-08-02

### Improved

- **Умный поиск** — при однозначном запросе Enter сразу открывает книги/авторов/серии; смешанный запрос по-прежнему показывает хаб; ссылка «Все разделы» (`hub=1`)
- **Скорость поиска** — обзор считает только totals; прогрев страницы книг в фоне; ленивые жанры; стоп-слова в FTS/LIKE; дедуп изданий на странице
- Подсказки в поле ввода через `/api/search/suggest` (debounce, для длинных запросов — поиск по названию)
- «Другие книги автора» корректно резолвят каноническое имя автора
- Страница книги Flibusta: аннотация из sidecar без открытия архива FB2

### Fixed

- Медленное открытие «Книги» из хаба поиска на больших библиотеках
- Авто-пересборка FTS при dirty/desync с горячего пути поиска

## [1.7.6] - 2026-06-14

### Added

- **Telegram-бот** — поиск книг, авторов и серий; умный ввод без команд; скачивание в нескольких форматах.
- Карточки книг в боте с обложкой и аннотацией.
- Страница **Админка → Telegram-бот**: токен, список пользователей, описание профиля, текст `/start`.
- Режим **webhook** (`TELEGRAM_WEBHOOK_URL`) или long polling; меню команд; кнопка «Назад»; очистка старых сообщений при пагинации.
- Безопасные URL **`/book/b64/…`** для книг с управляющими символами в ID (обход 400 от nginx и прокси).
- Профиль: блоки «Читаю», закладки читалки и заметки; навигация по разделам аккаунта.
- Пагинация в избранном (книги и прочитанные); раздел «Прочитанные».
- Читалка: выбор шрифта (системные и Google Fonts), пресеты вёрстки, настройки полей и ширины колонки.
- Улучшения **TTS**: чтение в фоне, остановка долгим нажатием.

### Changed

- «Продолжить чтение» на главной подгружается отдельно и не блокирует страницу.
- При сортировке по серии номер книги в серии учитывается раньше релевантности поиска.
- OPDS и веб-ссылки на книги используют схему book-ref.

### Fixed

- Удаление записи из истории чтения возвращает корректные ошибки при неверном ID или отсутствии записи.
- Настройки Telegram-бота в админке сохраняются надёжно (флаг `telegram_configured`, без перезаписи env).
