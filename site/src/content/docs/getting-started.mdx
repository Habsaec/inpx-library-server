<Steps>

1. **Войдите** как **admin / admin** и сразу смените пароль в профиле. Интерфейс переключается на английский кнопкой **EN** в верхней панели.

2. **Добавьте источник.** Админка → **Источники книг → Добавить**: путь к файлу `.inpx`, к библиотеке Calibre или к папке с книгами. В Docker это путь внутри контейнера, например `/library`.

3. **Дождитесь индексации.** Прогресс виден в админке; коллекция из сотен тысяч книг индексируется около 45 минут. Сервер всё это время отвечает на запросы.

4. **Создайте пользователей** в **Админка → Пользователи** или включите там анонимный доступ.

5. **Почта и Telegram** (по желанию). Для отправки книг на читалки заполните **Админка → Почта**, для бота — **Админка → Telegram-бот**.

6. **Бэкап.** **Админка → Бэкап** — переносимая копия пользовательских данных (см. ниже).

</Steps>

## Бэкап

Каталог всегда можно пересобрать из источников, поэтому в бэкап входят **пользовательские данные**: пользователи, настройки, источники, полки и умные полки, избранное, прочитанное, позиции чтения, закладки и заметки. Книги находятся по отпечатку файла, поэтому бэкап работает и после полной переиндексации.

- Ежедневная копия с ротацией включена по умолчанию (хранится 7 последних).
- **Пароль бэкапа** шифрует каждую копию (AES-256-GCM) и только тогда переносит секреты — SMTP, токен бота, OIDC. Без пароля файл открытый и без секретов.
- Восстановление — из загруженного файла или из сохранённой копии; есть проверка без записи.

<Aside type="note">
Полной копии базы в приложении нет намеренно: на файле в несколько гигабайт она подвешивала сервер. Чтобы скопировать сам файл, остановите сервер и скопируйте `data/library.db`.
</Aside>

## Где что лежит

| Что | Где |
|---|---|
| База, настройки, кэш обложек | `data/` (том `inpx-data` в Docker) |
| Журнал сервера | `data/runtime.log` |
| Проверка работоспособности | `http://<сервер>:3000/health` |
