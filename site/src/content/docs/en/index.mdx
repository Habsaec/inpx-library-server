## What it does

<CardGrid>
  <Card title="Catalog and search" icon="magnifier">
    Full-text search with suggestions and typo correction, authors, series, genres, languages, filters, new arrivals and recommendations. Built for hundreds of thousands of books.
  </Card>
  <Card title="In-browser reader" icon="open-book">
    FB2 and EPUB: themes, fonts, bookmarks, color-coded notes, read aloud. Your position syncs with your phone without «jumps».
  </Card>
  <Card title="Personal library" icon="star">
    Reading, Want to read, ratings, favorite authors and series, «New from favorites», shelves and smart shelves, a yearly goal, import from Goodreads and LiveLib.
  </Card>
  <Card title="Delivery" icon="rocket">
    FB2, FB2.ZIP, EPUB, MOBI, AZW3 and more, batch ZIP, send to Kindle, PocketBook or Kobo by e-mail and to Telegram.
  </Card>
  <Card title="Clients" icon="laptop">
    Android app, OPDS 1.x / 2 with reading progress, KOReader progress sync (KOSync), a Telegram bot with search.
  </Card>
  <Card title="Sources" icon="random">
    INPX collections (ZIP / 7z), Calibre libraries and plain folders; several sources at once, folder watching, duplicate cleanup.
  </Card>
</CardGrid>

## Quick start

```bash
docker run -d \
  --name inpx-library \
  --restart unless-stopped \
  -p 3000:3000 \
  -v inpx-app:/app \
  -v inpx-data:/app/data \
  -v /path/to/library:/library:ro \
  -e LIBRARY_ROOT=/library \
  habsaec/inpx-library-server:latest
```

Open [http://localhost:3000](http://localhost:3000) and sign in as **admin / admin** (change the password in your profile right away). See [Installation](./install/) for Docker, Windows, Linux, macOS and Synology.
