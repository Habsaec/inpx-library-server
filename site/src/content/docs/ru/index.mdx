## Быстрый старт

```bash
docker run -d \
  --name inpx-library \
  --restart unless-stopped \
  -p 3000:3000 \
  -v inpx-app:/app \
  -v inpx-data:/app/data \
  -v /path/to/library:/library:ro \
  -e LIBRARY_ROOT=/library \
  habsaec/inpx-library-server:latest
```

Откройте [http://localhost:3000](http://localhost:3000) и войдите как **admin / admin** (пароль сразу смените в профиле). Подробнее — в разделе [«Установка»](./install/) для Docker, Windows, Linux, macOS и Synology.

## Проект

- **Сервер** — [inpx-library-server](https://github.com/Habsaec/inpx-library-server): индекс, веб, OPDS, API.
